## 🚀 طريقة التشغيل على GitHub Pages

### الخطوة 1: إنشاء مستودع جديد
1. ادخل إلى حسابك على [GitHub](https://github.com).
2. اضغط على **New repository**.
3. سمِّ المستودع كما تريد، مثال: `dual-consciousness-lab`.
4. اختر **Public** (مجاني).
5. لا تحدد أي قالب، واضغط **Create repository**.

### الخطوة 2: رفع الملفات
#### عبر الواجهة الرسومية:
1. داخل المستودع اضغط على **Add file → Upload files**.
2. اسحب الملفين `index.html` و `README.md` إلى منطقة الرفع.
3. اضغط **Commit changes**.

#### أو عبر Git Bash / Terminal:
```bash
git clone https://github.com/yourusername/dual-consciousness-lab.git
cd dual-consciousness-lab
# انسخ index.html و README.md إلى هذا المجلد
