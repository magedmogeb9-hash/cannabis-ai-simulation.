# 🧠 منصة الذكاء الاصطناعي متعددة المهارات — دردشة حية بدون مفاتيح

**Multi-Skill AI Chat Platform (Free & Open Source)**

منصة ويب متكاملة تعمل بملفين فقط (`index.html` و `README.md`) يمكن رفعهما على GitHub Pages مجانًا. تستخدم نماذج مفتوحة المصدر مجانية عبر واجهة **Pollinations AI** ولا تتطلب أي مفاتيح API.

---

## ✨ المهارات المتاحة

| الوضع | الوصف |
|-------|-------|
| 💬 **مساعد عام** | محادثة ذكية تقليدية مع ردود مفيدة ودقيقة. |
| 🌿 **الوضع المزدوج (THC)** | محاكاة العقل تحت تأثير القنب مقابل العقل الصريح، مع مؤقت زمني ورسم بياني حي. |
| 👨‍💻 **مبرمج** | كتابة أكواد نظيفة مع شرح وتعليقات. |
| 🌐 **مترجم** | ترجمة النصوص مع الحفاظ على السياق والمعنى. |
| 📝 **ملخّص** | تلخيص النصوص الطويلة واستخراج النقاط الرئيسية. |
| 🎨 **كاتب إبداعي** | توليد نصوص أدبية وقصص مبتكرة. |

---

## ⚙️ التقنيات المستخدمة

- **HTML5 + CSS3 + JavaScript** نقي بدون أطر عمل.
- **Chart.js** للرسم البياني التفاعلي (فقط في الوضع المزدوج).
- **Pollinations AI** — واجهة مجانية مفتوحة المصدر لتوليد النصوص بدون مفاتيح.
  - تدعم النماذج: `openai`, `gpt-3.5-turbo`, `mistral` وغيرها.

## 🚀 النشر على GitHub Pages

### 1. إنشاء مستودع
- أنشئ مستودعًا جديدًا على GitHub (Public).
- سمِّه `ai-free-chat`.

### 2. رفع الملفات
- ارفع `index.html` و `README.md` إلى المستودع.

### 3. تفعيل Pages
- اذهب إلى **Settings → Pages**.
- اختر **Branch: main** و **Folder: / (root)**.
- اضغط **Save**.

### 4. الاستخدام
- افتح الرابط `https://yourusername.github.io/ai-free-chat/`.
- اختر المهارة المطلوبة.
- ابدأ الدردشة مباشرة — لا حاجة لأي مفاتيح.

## 🧪 ملاحظات حول الوضع المزدوج

- يتم إرسال طلبين متوازيين لنفس السؤال:
  - **الوعي المشوه**: `temperature=1.0` مع برومبت خاص يحاكي تأثير THC.
  - **العقل الصريح**: `temperature=0.0` مع برومبت تحليلي صارم.
- الرد المشوه يظهر فورًا، بينما الرد الصريح يتأخر لمدة عشوائية (20-45 ثانية) محاكاة لتلاشي تأثير THC.
- شريط تقدم ورسم بياني يوضحان التغير المعرفي خلال فترة الانتظار.

## 📌 ملاحظات فنية حول الاتصال المجاني

- الواجهة المستخدمة هي **Pollinations AI** وهي خدمة مجانية تسمح بالاتصال بنماذج لغوية مختلفة.
- الكود يحاول الاتصال بعدة نماذج (مثل `openai`, `gpt-3.5-turbo`, `mistral`) مع دعم طريقة POST و GET كخيار احتياطي.
- إذا واجهت أخطاء في الاتصال، تأكد من أن الخدمة متاحة وأن المتصفح يسمح بالطلبات عبر الإنترنت.
