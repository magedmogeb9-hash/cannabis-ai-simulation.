# 🧠 منصة الذكاء الاصطناعي متعددة المهارات — بدردشة حية

**Multi-Skill AI Chat Platform with Dual Consciousness Mode**

منصة ويب متكاملة تعمل بملفين فقط (`index.html` و `README.md`) يمكن رفعهما على GitHub Pages مجانًا. تتصل مباشرة بخوادم OpenAI عبر مفتاح API الخاص بالمستخدم، وتوفر واجهة دردشة حية مع **عدة مهارات ذكاء اصطناعي** بالإضافة إلى **وضع المحاكاة المزدوجة (تأثير THC)**.

---

## ✨ المهارات المتاحة

| الوضع | الوصف |
|-------|-------|
| 💬 **مساعد عام** | محادثة ذكية تقليدية مع ردود مفيدة ودقيقة. |
| 🌿 **الوضع المزدوج (THC)** | محاكاة العقل تحت تأثير القنب مقابل العقل الصريح، مع مؤقت زمني ورسم بياني حي. |
| 👨‍💻 **مبرمج** | كتابة أكواد نظيفة مع شرح وتعليقات. |
| 🌐 **مترجم** | ترجمة النصوص مع الحفاظ على السياق والمعنى. |
| 📝 **ملخّص** | تلخيص النصوص الطويلة واستخراج النقاط الرئيسية. |
| 🎨 **كاتب إبداعي** | توليد نصوص أدبية وقصص مبتكرة. |

---

## ⚙️ التقنيات المستخدمة

- **HTML5 + CSS3 + JavaScript** نقي بدون أطر عمل.
- **Chart.js** للرسم البياني التفاعلي (فقط في الوضع المزدوج).
- **OpenAI API** (`gpt-4o-mini`) للردود.
- **LocalStorage** لحفظ مفتاح API محليًا.

---

## 🚀 النشر على GitHub Pages

### 1. إنشاء مستودع
- أنشئ مستودعًا جديدًا على GitHub (Public).
- سمِّه `ai-multi-skill-chat`.

### 2. رفع الملفات
- ارفع `index.html` و `README.md` إلى المستودع.

### 3. تفعيل Pages
- اذهب إلى **Settings → Pages**.
- اختر **Branch: main** و **Folder: / (root)**.
- اضغط **Save**.

### 4. الاستخدام
- افتح الرابط `https://yourusername.github.io/ai-multi-skill-chat/`.
- أدخل مفتاح OpenAI API (يبدأ بـ `sk-`).
- اختر المهارة المطلوبة.
- ابدأ الدردشة.

---

## 🔑 الحصول على مفتاح OpenAI API

1. تفضل بزيارة [platform.openai.com/api-keys](https://platform.openai.com/api-keys).
2. سجّل الدخول أو أنشئ حسابًا.
3. اضغط **Create new secret key**.
4. انسخ المفتاح والصقه في الحقل المخصص.

> **تنبيه:** المفتاح يُحفظ فقط في متصفحك (LocalStorage) ولا يُرسل إلى أي خادم وسيط.

## 🧪 ملاحظات حول الوضع المزدوج

- يتم إرسال طلبين متوازيين لنفس السؤال:
  - **الوعي المشوه**: `temperature=1.0` + `presence_penalty=0.7` + `frequency_penalty=0.6`.
  - **العقل الصريح**: `temperature=0.0`.
- الرد المشوه يظهر فورًا، بينما الرد الصريح يتأخر لمدة عشوائية (20-45 ثانية) محاكاة لتلاشي تأثير THC.
- شريط تقدم ورسم بياني يوضحان التغير المعرفي خلال فترة الانتظار.
