# 🔬 Cannabis Cognitive AI Simulation Web-Lab

مختبر علمي تفاعلي يعمل مباشرة من المتصفح لمحاكاة التغيرات الإدراكية والسلوكية للإنسان عند تعاطي أوراق القنب (مادة THC) باستخدام نماذج الذكاء الاصطناعي اللغوية عبر نظام **انقسام الوعي المتزامن**.

## 🚀 طريقة التجغيل والوصول للموقع
الموقع يعمل مباشرة ومرفوع عبر **GitHub Pages**، يمكنك الوصول للرابط وتجربة المحاكاة فوراً من أي متصفح ويب.

## 🧠 آلية عمل المحاكاة في المختبر
1. **الوعي المشوه (الفوري):** يعطيك إجابة مباشرة متأثرة بـ (تشتت الانتباه، انخفاض معدل الذكاء السلوكي، التركيز المفرط العشوائي، والهلوسة اللفظية).
2. **الوعي الحقيقي الصريح (المؤجل التلقائي):** في الخلفية، يقوم النظام بتحليل السؤال بصراحة مطلقة وبدون أي قيود أو حياد سلوكي، وينتظر **عداداً زمنياً عشوائياً** يحاكي تلاشي تأثير المخدر من عقل الإنسان، ثم يقوم **بتحديث نص المحادثة الأولى تلقائياً** ليعرض الإجابة العلمية الواعية الرصينة في نفس المكان!
